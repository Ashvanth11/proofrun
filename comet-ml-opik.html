Summary

Sandbox testing confirmed opik's Python SDK can be installed via pip and used with @opik.track plus record_traces_locally() to capture a full trace (name, input, output, spans) entirely in-process, with no Comet account, API key, config file, or reachable server required. Background delivery to comet.com failed due to lack of network, but this did not affect the local recording capability.

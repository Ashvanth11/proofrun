Summary

The repository's own LICENSE file explicitly confirms an open-core model: content outside the ee/ (web/src/ee/, worker/src/ee/) directories is licensed under MIT (an OSI-approved license), while content within those directories is governed by a separate, non-open Enterprise License (ee/LICENSE) that restricts use, copying, and redistribution absent a commercial agreement. GitHub's own NOASSERTION license field reflects this mixed licensing rather than a single clean SPDX license. This directly answers the question: Langfuse's core is genuinely open source under MIT, but part of what is offered under the Langfuse name is under a separate commercial license, consistent with an 'open core' rather than fully open source project. Note that the README excerpt actually read was truncated to navigation/header content and did not itself surface license badges or wording, so no claim is made here about how the README specifically frames or omits the commercial-license caveat.

microsoft/markitdown · 2026-11-07

A Word document in. Structured Markdown out.

A freshly generated Word document became Markdown with its heading and table cell contents intact. The complete conversion ran locally in the network-disabled sandbox, with no LLM client configured.

Historical rerun · Docker execution · estimated token cost $0.109

The repository
Microsoft’s Python tool for converting documents into Markdown, a plain-text document format.
The claim tested
A Word document can be converted to Markdown while preserving its heading and table contents, without an LLM API.
How we tested it
Created a DOCX file with one heading and a 2×2 table, then ran MarkItDown’s default converter in a Docker sandbox with runtime network access disabled.

What the experiment established

  • A level-1 Word heading became “# My Test Heading”.
  • All four table values survived in Markdown table rows: Name, Value, Alpha, and 42.

Recorded output

# My Test Heading

|  |  |
| --- | --- |
| Name | Value |
| Alpha | 42 |

Scope of this finding

  • One simple DOCX file was tested. Nested or merged tables, images, styles, and malformed documents were not tested.
  • The output adds an empty Markdown header row. This establishes preservation of the table content, not identical formatting or header semantics.
  • The source checkout was installed in editable mode with its DOCX dependencies. No explicit repository commit hash was captured.

Presentation review: The presentation is based on the actual command output. The original inconclusive investigation is preserved below; it is not overwritten by this rerun. This finding makes no licensing claim.

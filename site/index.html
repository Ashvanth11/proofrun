microsoft/markitdown ↗Supported · reviewed scope

A Word document in. Structured Markdown out.

The repository
Microsoft’s Python tool for converting documents into Markdown, a plain-text document format.
The claim tested
A Word document can be converted to Markdown while preserving its heading and table contents, without an LLM API.
How we tested it
Created a DOCX file with one heading and a 2×2 table, then ran MarkItDown’s default converter in a Docker sandbox with runtime network access disabled.

What we found

A freshly generated Word document became Markdown with its heading and table cell contents intact. The complete conversion ran locally in the network-disabled sandbox, with no LLM client configured.

Check 01A level-1 Word heading became “# My Test Heading”.
Check 02All four table values survived in Markdown table rows: Name, Value, Alpha, and 42.

pydantic/pydantic-ai ↗Supported · reviewed scope

Typed output, tested beyond the happy path.

The repository
A Python library for building AI agents with structured outputs validated against Pydantic schemas.
The claim tested
An agent configured with a structured output type returns a matching model for valid data and rejects data that violates the schema.
How we tested it
Ran the library with its local TestModel backend and a City schema containing two string fields. Tested valid data, then supplied an integer for one field and inspected the resulting error.

What we found

Pydantic AI returned a declared City model for valid test output. Deliberately invalid output triggered the library’s output-retry error. Both checks ran against the actual library using its local TestModel backend.

Check 01Valid test output returned an actual City model instance.
Check 02An integer in a string field triggered UnexpectedModelBehavior after the output retry limit.
